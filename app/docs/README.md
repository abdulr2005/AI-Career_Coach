# AI Career Coach

> Helping people build better careers using Artificial Intelligence.

---

# About

AI Career Coach is an open-source AI platform designed to help people improve their resumes, understand job requirements, prepare for interviews, and build personalized learning roadmaps.

This project is not built for profit.

The mission is simple:

Help as many people as possible find better career opportunities using AI.

Whether someone is a fresh graduate, an experienced professional, or changing careers, the platform aims to provide clear, personalized guidance.

---

# Vision

Finding a job shouldn't depend on luck.

Many talented people are rejected simply because they don't know:

- Why their resume was rejected.
- Which skills are missing.
- What recruiters are looking for.
- How to prepare for interviews.
- Which courses to study.
- How to improve step by step.

AI Career Coach was created to solve those problems.

The goal is to build one intelligent platform that supports people throughout their entire career journey.

# Main Features

## Resume Analysis (ATS)

Analyze resumes using an AI-powered ATS engine.

Features include:

- Resume parsing
- Resume quality analysis
- Project evaluation
- Skills extraction
- Experience analysis
- Certification analysis
- Resume scoring
- AI recommendations

---

## Job Description Analysis

Analyze job descriptions from any company.

Extract:

- Required skills
- Soft skills
- Experience level
- Education
- Responsibilities
- Qualifications

---

## Resume vs Job Matching

Compare resumes with job descriptions.

Show:

- Match percentage
- Missing skills
- Strengths
- Weaknesses
- Improvement suggestions

---

## Learning Roadmap

Generate a personalized roadmap based on missing skills.

The roadmap adapts to every user's career goal.

---

## Course Recommendation

Recommend learning resources from trusted platforms.

Examples:

- Coursera
- edX
- Udemy
- Microsoft Learn
- Google
- Cisco
- Kaggle

---

## AI Interview Preparation

Generate interview questions.

Practice interviews with AI.

Receive feedback on:

- Answers
- Communication
- Confidence

---

## Voice Analysis

Analyze:

- Speaking speed
- Fluency
- Confidence
- Pauses
- Pronunciation

---

## Vision Analysis

Analyze webcam input during interviews.

Detect:

- Eye contact
- Facial expressions
- Body posture
- Confidence indicators

---

## AI Career Assistant

An intelligent assistant capable of answering career-related questions and helping users throughout their career journey.

# Project Structure

The project is divided into two major parts.

## Artificial Intelligence

Responsible for:

- Resume Analysis
- ATS
- Matching
- Recommendation
- Roadmaps
- Interview AI
- Voice AI
- Vision AI
- LLM Assistant

---

## Software Engineering

Responsible for:

- Backend
- Frontend
- Database
- Authentication
- API
- Deployment
- Docker
- Infrastructure

Both parts communicate only through APIs.

This architecture allows independent development.
