# Current AI Progress

This document explains everything that has already been built.

At the moment, the AI side of the project is focused on building a strong ATS engine.

The following modules are already completed.

✔ Resume PDF Reader

Reads PDF resumes and extracts the text.

------------------------------------------------

✔ Resume Cleaner

Removes unnecessary information such as contact headers while preserving useful content.

------------------------------------------------

✔ Section Parser

Automatically detects sections like:

Summary

Education

Projects

Skills

Experience

Certifications

Awards

------------------------------------------------

✔ Skill Extractor

Extracts technical skills from the resume.

------------------------------------------------

✔ Project Splitter

Separates multiple projects into individual projects.

------------------------------------------------

✔ Project Feature Extractor

Extracts useful information from each project.

Skills

Metrics

Achievements

Action Verbs

Impact

Links

Teamwork

------------------------------------------------

✔ Project Scoring Engine

Scores every project independently.

------------------------------------------------

✔ Experience Analyzer

Analyzes experience and extracts reusable information.

------------------------------------------------

✔ Certification Analyzer

Analyzes certifications.

------------------------------------------------

✔ ATS Score Builder

Calculates resume quality scores.

------------------------------------------------

✔ Summary Builder

Generates strengths.

Generates weaknesses.

Generates recommendations.

✔ Report Builder
